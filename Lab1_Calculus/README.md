# Лабораторная работа №1. Математический анализ и матричное исчисление

**Ноутбук:** [lab1.ipynb](lab1.ipynb)

## О чем работа

В работе по шагам разобраны производные: сначала для функции одной переменной, потом градиент, якобиан, гессиан и матричные градиенты. В конце все это применяется к одной составной функции, которая минимизируется градиентным спуском. Сквозной пример считается на одном общем наборе данных.

## Что сделано

- Переписал суммы по индексам в матричном виде и проверил это через циклы, матричные операции и `np.einsum`.
- Посчитал производные функций одной переменной: по определению, по правилам дифференцирования и численно. Отдельно разобрал точку, где функция не дифференцируема.
- Нашел частные производные, градиент и полный дифференциал, построил касательную плоскость.
- Посчитал производную по направлению и полную производную, когда переменная влияет на результат по нескольким путям.
- Вывел якобиан векторной функции, посчитал произведения JVP и VJP и цепное правило для композиции.
- Построил гессиан, по нему определил минимум и седловую точку, проверил квадратичную модель.
- Вывел градиенты по векторам и матрицам, в том числе через след.
- Для сквозной составной функции вывел производные по всем параметрам вручную и проверил их конечными разностями.
- Запустил градиентный спуск и посмотрел, как размер шага влияет на сходимость.

## Результат

Все ручные выводы оформлены в Markdown и проверены численно: аналитические и численные градиенты совпали. Для градиентного спуска с тремя размерами шага построены графики функции потерь и нормы градиента.
