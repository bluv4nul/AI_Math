# Лабораторная работа №3. Скалярный autograd и обучение одного нейрона

**Ноутбук:** [lab3.ipynb](lab3.ipynb)

## О чем работа

Свой маленький механизм автоматического дифференцирования, как в PyTorch, только для скаляров и без сторонних библиотек. Потом на нем обучается один нейрон.

## Что сделано

- Написал класс `Value`: каждая операция создает вершину вычислительного графа и запоминает свое локальное правило производной.
- Реализовал сложение, умножение, вычитание, степень, `sin`, `exp`, `log` и `tanh`.
- Сделал обратный проход по графу в обратном топологическом порядке с накоплением градиентов в общих вершинах.
- Вручную разобрал обратный проход для `tanh(ab + a)` по шагам и сверил его с обычным дифференцированием.
- Проверил градиенты центральной разностью.
- Собрал нейрон `tanh(wx + b)`, вывел градиенты MSE по весу и смещению и обучил нейрон градиентным спуском.
- Ответил на вопросы для самопроверки.

## Результат

- Для `a·a + a` при `a = 2` градиент равен 5, как и должно быть по формуле `2a + 1`.
- Градиент `Value` совпал с численным с ошибкой около `1e-10`.
- После 80 эпох ошибка нейрона упала с 1.0 до 0.026, точность классификации 100 %.

Python (только стандартная библиотека), Matplotlib для графика.
