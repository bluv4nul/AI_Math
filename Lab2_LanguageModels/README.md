# Лабораторная работа №2. Основы языковых моделей

**Ноутбук:** [lab2.ipynb](lab2.ipynb)  
**Данные:** [data/greenfield_town.json](data/greenfield_town.json) - небольшой учебный корпус "Greenfield Town"

## О чем работа

В работе текст разными способами превращается в числа, а потом на нем строятся простые языковые модели. Начинается все с мешка слов, заканчивается счетной триграммной моделью и метриками качества текста.

## Что сделано

- Токенизировал текст, собрал словарь и бинарные BoW-векторы, посмотрел, какую часть порядка слов возвращают биграммы.
- Посчитал softmax и кросс-энтропию вручную, затем собрал на PyTorch простой классификатор текстов по темам.
- Обучил skip-gram эмбеддинги слов и нашел ближайших соседей по косинусному сходству.
- Реализовал подсловную токенизацию BPE: обучение слияний и разбиение новых слов, в том числе с неизвестными символами.
- Собрал триграммную языковую модель: посчитал вероятности продолжений по частотам и сгенерировал текст.
- Посчитал перплексию и ROUGE, рейтинг Elo по попарным сравнениям, сделал ручную оценку по шкале Лайкерта.
- Собрал результаты всех частей в один итоговый отчет с проверками и ограничениями каждого метода.

## Результат

Все части работают на одном корпусе. Классификатор правильно определяет тему документа, skip-gram для слова `gardener` ближайшим соседом выдает `garden`, перплексия триграммной модели на тестовой последовательности равна 5.63.
