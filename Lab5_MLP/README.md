# Лабораторная работа №5. Самописный MLP на CPU

**Ноутбук:** [lab5.ipynb](lab5.ipynb)

## О чём работа

Многослойный перцептрон написан на NumPy без библиотек для нейросетей и обучен алгоритмом обратного распространения ошибки с mini-batches. Задача — бинарная классификация опухолей на датасете Breast Cancer Wisconsin (Diagnostic).

## Что сделано

- Загрузил датасет (569 объектов, 30 числовых признаков), перекодировал метку: M → 1, B → 0.
- Разбил данные на train/val/test 60/20/20 со стратификацией и стандартизировал признаки по обучающей выборке.
- Написал класс `MLP`: прямой проход, обратное распространение, обновление весов, L2-регуляризация.
- Написал функцию `train` с mini-batches, ранней остановкой по валидации и историей обучения в `pandas.DataFrame`.
- Построил кривые loss и accuracy на обучении и валидации.
- Подобрал порог τ по максимуму F1 на валидации.
- Посчитал Accuracy, F1, ROC-AUC, PR-AUC и матрицу ошибок на тестовой выборке.

## Модель и гиперпараметры

Архитектура 30 → 64 (ReLU) → 32 (ReLU) → 1 (сигмоида), функция потерь — бинарная кросс-энтропия. SGD, батч 32, скорость обучения 0.05, L2 с коэффициентом 0.001, максимум 100 эпох, ранняя остановка после 15 эпох без улучшения `val_loss`.

## Результат

Обучение остановилось на 41-й эпохе, лучшие веса взяты с 26-й (`val_loss` = 0.0565). Выбран порог τ = 0.25.

| Метрика на test | τ = 0.5 | τ = 0.25 |
|---|---|---|
| Accuracy | 0.9825 | 0.9649 |
| F1 | 0.9756 | 0.9535 |
| Recall | 0.9524 | 0.9762 |

ROC-AUC = 0.994, PR-AUC = 0.9923. При τ = 0.25 из 114 тестовых объектов ошибок 4: одна пропущенная злокачественная опухоль и три ложные тревоги. При τ = 0.5 ложных тревог нет, но пропущенных опухолей две.

## Стек

Python, NumPy, pandas, Matplotlib, scikit-learn (данные, разбиение, стандартизация, метрики).
